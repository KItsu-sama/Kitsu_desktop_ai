# Setup System — Complete Architecture

## Overview

The setup system follows strict architectural separation:

```bash
launcher.py (orchestrator)
    ↓
first_run.py (config writer)
    ↓
setup_wizard.py (UI layer)
    ↓
Returns config dict (NO file writing)
```

---

## File Responsibilities

### `launcher.py`

**Role:** Main orchestrator  
**Responsibilities:**

- Detect first-run state
- Call `first_run.py` if needed
- Load all configs
- Build `RuntimeConfig`
- Pass to `main.py`

**MUST NOT:**

- Write config files
- Run async code
- Start runtime

---

### `scripts/first_run.py`

**Role:** Configuration writer  
**Responsibilities:**

- Detect system capabilities
- Run `SetupWizard` (interactive or headless)
- Write ALL config files:
  - `data/config/system_config.json`
  - `data/config/user_profile.json`
  - `data/config/permissions.json`
  - `data/config/personality.json`
  - `data/config.json`
  - `data/runtime/feature_manifest.json`
- Create directory structure
- Install/enable selected features

**MUST NOT:**

- Start runtime
- Import core modules
- Run async code

---

### `scripts/setup_wizard.py`

**Role:** UI layer (interactive configuration)  
**Responsibilities:**

- Ask user questions
- Validate inputs
- **Return configuration dict**
- Support headless mode (apply_defaults)

**MUST NOT:**

- Write files (returns dict only)
- Start runtime
- Import core modules (except emotion_config for validation)

---

## Complete Flow

### First Launch

```bash
$ python launcher.py
    ↓
launcher.is_first_run()
    ↓
  YES → Run first_run.py
    ↓
first_run.detect_system_info()
    ├─ Platform: linux/windows/macos
    ├─ GPU: Check PyTorch
    ├─ Audio: Check PyAudio
    └─ Headless: Check TTY
    ↓
first_run.run_setup_wizard()
    ├─ Interactive? → SetupWizard.run()
    └─ Headless? → SetupWizard.apply_defaults()
    ↓
SetupWizard returns config dict
    {
      "user_profile": {...},
      "permissions": {...},
      "personality": {...},
      "runtime": {...},
      "features": {...}
    }
    ↓
first_run writes all files
    ├─ system_config.json
    ├─ user_profile.json
    ├─ permissions.json
    ├─ personality.json
    ├─ config.json
    └─ feature_manifest.json
    ↓
first_run creates directories
    ├─ data/config/
    ├─ data/runtime/
    ├─ data/memory/
    ├─ data/logs/
    └─ data/learning/
    ↓
first_run installs features
    └─ Based on feature_manifest.json
    ↓
launcher marks first-run complete
    └─ Creates data/runtime/.first_run_complete
    ↓
launcher loads all configs
    ↓
launcher builds RuntimeConfig
    ↓
launcher calls main.py(runtime_config)
    ↓
[KITSU STARTS]
```

## Feature Selection Flow

```bash
SetupWizard._setup_features()
    ↓
Load docs/featurespec.json
    ↓
For each feature:
    ├─ Check requirements vs capabilities
    ├─ Can enable? → Ask user
    └─ Cannot enable? → Skip
    ↓
Return {feature_id: enabled}
    ↓
first_run.write_feature_manifest()
    ↓
first_run.install_features()
    └─ Create directories
    └─ Download files (if needed)
```

## Headless Installation

For servers/containers:

```bash
$ python launcher.py
```

**Flow:**

1. Detects non-interactive (no TTY)
2. `first_run.py` skips wizard
3. Calls `wizard.apply_defaults()`
4. Writes default configs
5. Launches with safe defaults

**Result:** Text mode, safe permissions, no voice/avatar

## Key Invariants

**setup_wizard.py:**

- Returns dict ONLY
- Never writes files
- Only imports emotion_config for validation

**first_run.py:**

- ONLY component that writes setup configs
- Never starts runtime
- Never imports core runtime modules
- Works headless

**launcher.py:**

- ONLY component that detects first-run
- Never writes configs
- Never runs async
- Passes immutable RuntimeConfig

---

## Error Handling

```bash
first_run.py fails
    ↓
launcher.py logs error
    ↓
Exit(1) - prevents runtime from starting
```

```bash
setup_wizard.py crashes
    ↓
first_run.py catches exception
    ↓
Falls back to apply_defaults()
    ↓
Continues with safe defaults
```

## Summary

The new setup system:

1. **launcher.py** orchestrates everything
2. **first_run.py** writes all configs
3. **setup_wizard.py** returns config dict (no file I/O)
4. **featurespec.json** defines optional features
5. **All file writing** happens in first_run.py
6. **Clean separation** of concerns
7. **Headless support** built-in
8. **Architecture compliant**
